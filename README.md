# PONG

Полноэкранная копия классического PONG 1972 года для Windows 11.
Два игрока, звук как в оригинальном автомате, и **универсальная поддержка
геймпадов через SDL2**: Xbox (One / Series / 360), PlayStation
(DualShock 3/4, DualSense), Nintendo Switch Pro, Logitech, 8BitDo, Stadia,
Steam Controller и любой другой XInput- или DirectInput-контроллер,
который умеет SDL.

![Оригинал](pong-game.png)

## Запуск

Три способа, на выбор:

1. **`dist/PONG.exe`** — самодостаточный exe со встроенной иконкой, Python
   ставить не нужно. Собран через PyInstaller (см. раздел ниже).
2. **`PONG.bat`** — двойной клик. При первом запуске сам доставит `pygame-ce`,
   если её нет.
3. Из терминала: `python pong.py`.

## Управление

Каждая ракетка свободно двигается **в своей половине корта** — по обеим осям.

| Действие | Геймпад | Клавиатура |
|---|---|---|
| Ракетка вверх/вниз/влево/вправо | левый стик или крестовина (обе оси) | Игрок 1: `W` `A` `S` `D`, Игрок 2: стрелки |
| Начать / подать / играть ещё раз | `START`, `A`, `B`, `X`, `Y` (или `✕` / `◯` / `□` / `△` на PlayStation) | `Пробел` или `Enter` |
| Один игрок против компьютера | — | `1` |
| Два игрока | — | `2` |
| Пауза | — | `P` |
| Вернуться в меню | — | `R` |
| Окно / полный экран | — | `F11` или `Alt+Enter` |
| Выход | — | `Esc` |

Первый подключённый геймпад — левая ракетка, второй — правая.
Геймпады можно втыкать и вынимать прямо во время игры, игра их подхватит.

## Поддерживаемые геймпады

Через встроенный в SDL2 GameController API игра автоматически распознаёт
и раскладывает под единый Xbox-подобный маппинг любой из этих контроллеров:

* **Microsoft Xbox** — Xbox 360, Xbox One, Xbox Series X|S, Elite;
* **Sony PlayStation** — DualShock 3, DualShock 4, DualSense (PS5);
* **Nintendo Switch Pro Controller**, Joy-Con пара;
* **Logitech** — F310, F510, F710, Rumblepad 2, Dual Action и другие;
* **8BitDo**, **Stadia Controller**, **Steam Controller**, **NVIDIA Shield**;
* любой другой XInput- или DirectInput-контроллер, известный SDL.

Если геймпад SDL не узнал — игра всё равно попробует прочитать его как
«сырой» джойстик: левый стик и крестовина обычно работают сразу.

**Про XInput vs DirectInput.** У некоторых геймпадов (например, Logitech F310
и F710) снизу есть переключатель `X / D`:

* `X` (XInput) — рекомендуется, работает сразу;
* `D` (DirectInput) — тоже работает, игра читает и левый стик, и крестовину.

**Про вибрацию.** Игра посылает rumble при каждом отбитии. Геймпады с
моторами (Xbox, DualShock/DualSense, Switch Pro, Logitech F710 и т.п.)
дают отклик; пады без моторов (Logitech F310, некоторые бюджетные клоны)
просто игнорируют вызов.

Если ракетка «уезжает» сама — у стика великоват дрейф, увеличьте `DEADZONE`
в начале `pong.py` (0.22 → 0.30).

## Правила

Игра до **11 очков**. Мяч ускоряется с каждым отбитием — чем ближе к краю ракетки
вы его принимаете, тем острее угол. Классика: игра идёт на пас, а не на силу.

## Настройка под себя

Все параметры — в начале `pong.py`:

| Константа | Что делает |
|---|---|
| `WIN_SCORE` | до скольких очков играем |
| `PADDLE_H` | высота ракетки (больше = легче) |
| `PADDLE_SPEED` | скорость ракетки |
| `BALL_SPEED_START` / `BALL_SPEED_MAX` | начальная и максимальная скорость мяча |
| `BALL_SPEED_STEP` | насколько мяч ускоряется за удар |
| `DEADZONE` | мёртвая зона стика |

## Требования

Python 3.14 и `pygame-ce` (у обычной `pygame` пока нет сборки под 3.14 — ставится
именно `pygame-ce`, импортируется всё равно как `pygame`).

`pygame-ce` идёт вместе с SDL2, и в SDL2 уже встроена база маппингов
геймпадов от сообщества — поэтому большинство современных контроллеров
работают «из коробки», без дополнительных драйверов.

Для готового `dist/PONG.exe` ничего ставить не нужно.

## Сборка exe

Одноразово поставить PyInstaller:

```
python -m pip install pyinstaller
```

Собрать:

```
python -m PyInstaller --onefile --windowed --name PONG --icon pong.ico --noconfirm pong.py
```

Готовый файл окажется в `dist/PONG.exe` (~28 МБ). Иконка `pong.ico`
собирается из `pong-game.png` — если хочется её перегенерировать после правки
картинки, есть такой быстрый способ через Pillow:

```python
from PIL import Image
src = Image.open("pong-game.png").convert("RGBA")
size = max(src.size)
sq = Image.new("RGBA", (size, size), (0, 0, 0, 255))
sq.paste(src, ((size - src.width) // 2, (size - src.height) // 2), src)
sq.save("pong.ico", sizes=[(16,16),(32,32),(48,48),(64,64),(128,128),(256,256)])
```

Первый запуск exe чуть медленнее (~1–2 сек) — PyInstaller распаковывает
содержимое во временную папку. Windows SmartScreen может предупредить о
неподписанном файле — это ожидаемо для onefile-сборки без сертификата.
